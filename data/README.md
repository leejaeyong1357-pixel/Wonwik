# Wonpic 학습 데이터셋

원익 임직원 OPIc(Oral Proficiency Interview - computer) 학습용 데이터.

## 시험 개요

- **문항 수**: 15문항
- **시간**: 약 40분
- **형식**: 컴퓨터 기반 녹음 응답. 시험 전 배경 설문으로 본인 주제를 선택
- **판정**: ACTFL 기준 9등급 (NL ~ AL). 총점 방식이 아님
- **활용**: 사내 어학 인증, 승진·직무 배치 참고

## 문항 유형

| 유형 | 이름 | 내용 | 실제 시험 비중 |
|------|------|------|---------------|
| 1 | 자기소개 | 본인·직장·거주지·가족 소개 | 1문항 (고정) |
| 2 | 설문 주제 | 배경 설문에서 고른 주제. 묘사 → 습관 → 경험 콤보 | 약 6문항 |
| 3 | 돌발 주제 | 설문과 무관하게 나오는 공통 주제 | 약 3문항 |
| 4 | 롤플레이 | 상황 제시 후 질문하기 · 문제 해결 · 관련 경험 | 약 3문항 |
| 5 | 고난도 | 과거·현재 비교, 사회 이슈 분석 (IH·AL 목표) | 약 2문항 |

## 데이터 파일

| 파일 | 내용 | 개수 |
|------|------|------|
| `opic_type1_self_intro.json` | 자기소개 문항 + 모범답안 | 20 |
| `opic_type2_survey.json` | 설문 주제 문항 + 모범답안 | 20 |
| `opic_type3_unexpected.json` | 돌발 주제 문항 + 모범답안 | 20 |
| `opic_type4_roleplay.json` | 롤플레이 상황 + 문항 + 모범답안 | 20 |
| `opic_type5_advanced.json` | 고난도 문항 + 모범답안 | 20 |
| `opic_mock_exams.json` | 모의고사 세트 (15문항 구성) | 10 |

문항 스키마는 5유형 공통입니다.

```json
{
  "id": "t4_005",
  "type": 4,
  "category": "약속·모임",
  "difficulty": "medium",
  "situation": "예약한 식당이 갑자기 문을 닫았습니다.",
  "question": "...",
  "combo": "문제 해결",
  "follow_ups": ["..."],
  "keywords": ["..."],
  "sample_answer": "..."
}
```

`situation` 은 롤플레이(유형 4)에만, `combo` 는 콤보 단계가 있는 문항에만 있습니다.

## 데이터 출처

- 공개된 OPIc 시험 구성·유형 정보를 바탕으로 형식에 맞춰 자체 작성
- 실제 기출 문항이 아니며, 학습용으로만 사용합니다

## OPIc 등급 체계 (9등급)

| 등급 | 이름 | 수준 |
|------|------|------|
| NL | Novice Low | 단어 나열 수준 |
| NM | Novice Mid | 암기한 짧은 문장 |
| NH | Novice High | 익숙한 주제 단문 |
| IL | Intermediate Low | 문장을 이어서 말함 |
| IM1 | Intermediate Mid 1 | 문단 수준 답변 |
| IM2 | Intermediate Mid 2 | 사무직 지원 최소 구간 |
| IM3 | Intermediate Mid 3 | 사무직 일반 요구 구간 |
| IH | Intermediate High | 주요 기업·공공기관 선호 |
| AL | Advanced Low | 해외 업무·주재원 구간 |

## 앱 내부 환산 점수 (공식 점수 아님)

실제 OPIc 은 점수를 공개하지 않습니다. 학습자가 진척을 체감할 수 있도록
5개 평가 영역을 각 20점(합계 100점)으로 환산해 예상 등급을 매핑합니다.

| 영역 | 배점 | 판단 기준 |
|------|------|----------|
| 과제 수행 | 20 | 질문 의도에 맞게 답했는가 |
| 유창성 | 20 | 발화량·속도·끊김 |
| 어휘력 | 20 | 표현의 다양성과 정확성 |
| 문장 구성 | 20 | 문법 정확도와 문장 확장 |
| 전달력 | 20 | 발음·강세·명료도 |

| 환산 점수 | 등급 |
|----------|------|
| 0 ~ 14 | NL |
| 15 ~ 24 | NM |
| 25 ~ 34 | NH |
| 35 ~ 44 | IL |
| 45 ~ 54 | IM1 |
| 55 ~ 64 | IM2 |
| 65 ~ 74 | IM3 |
| 75 ~ 87 | IH |
| 88 ~ 100 | AL |

## 문항 난이도 기준

| 난이도 | 권장 목표 등급 | 응답 길이 |
|--------|--------------|----------|
| easy | IL ~ IM1 | 40~80단어 |
| medium | IM2 ~ IM3 | 80~150단어 |
| hard | IH ~ AL | 150단어 이상 |
